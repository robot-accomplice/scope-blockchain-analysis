# Report Generation Dataflow

Dataflow for all report-generating commands and the batch report.

## Report Types Overview

```mermaid
flowchart LR
    subgraph Commands
        A[address --report]
        B[crawl --report]
        C[portfolio summary --report]
        D[market summary --report]
        E[compliance risk --output]
        F[compliance compliance-report]
        G[report batch]
    end

    subgraph Generators
        A --> H[address_report::generate_address_report]
        B --> I[report::generate_report]
        C --> J[portfolio_summary_to_markdown]
        D --> K[market_summary_to_markdown]
        E --> L[format_risk_report]
        F --> M[format_compliance_report]
        G --> N[batch_report_to_markdown]
    end

    subgraph Output
        H --> O[MD file]
        I --> O
        J --> O
        K --> O
        L --> P[JSON/YAML/MD by extension]
        M --> O
        N --> O
    end
```

## Report Batch Dataflow

```mermaid
flowchart TB
    subgraph Resolve
        A[--addresses a,b,c or --from-file path] --> B[resolve_targets]
        B --> C[Vec of address, chain]
    end

    subgraph PerAddress
        C --> D[For each: address::analyze_address]
        D --> E[ChainClient from factory]
        E --> F[get_balance, get_transactions, get_token_balances]
        F --> G[AddressReport]
        C --> R{--with-risk?}
        R -->|Yes| S[RiskEngine.assess_address]
        S --> T[RiskAssessment]
    end

    subgraph Combine
        G --> H[batch_report_to_markdown]
        T -.->|per address| H
        H --> I[Header + address_report_section + Risk if --with-risk]
        I --> J[report_footer]
        J --> K[std::fs::write]
    end
```

## Report Footer (Versioning)

All reports include:

```
---
*Report generated by Scope vX.Y.Z at YYYY-MM-DD HH:MM:SS UTC. Always verify data from primary sources.*
```

From `display::report::report_footer()`.
